# Instrucciones del proyecto

## Migración MongoDB → SQL Server en curso

Este proyecto está en medio de una migración de MongoDB a SQL Server,
módulo por módulo. **Lee [MIGRACION_STATUS.md](MIGRACION_STATUS.md) primero**
en cualquier sesión nueva — tiene el estado por fase, decisiones de
arquitectura ya tomadas, y el siguiente paso pendiente.

## Mantenimiento de README.md

Cada vez que se haga un cambio relevante en el sistema (nuevo módulo/endpoint, cambio de
flujo funcional, nueva variable de entorno, nueva dependencia, cambio de stack, etc.),
actualiza [README.md](README.md) en el mismo cambio para reflejarlo. No es necesario
actualizarlo para cambios triviales (fixes menores de UI, typos, refactors internos sin
impacto visible).
