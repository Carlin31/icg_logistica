Reacomodamiento — Configuración
Reasigna vehículos a rutas usando la configuración de capacidad definida. Las asignaciones existentes se reemplazan completamente.
Tolerancia de capacidad
Rango válido: 70 % – 130 % de la capacidad del vehículo.
Cómo funciona el algoritmo
  1. Las rutas se ordenan de menor a mayor carga (kg).
  2. Los vehículos se ordenan de menor a mayor capacidad.
  3. Cada vehículo se usa máximo una vez por día.
  4. Se asigna el vehículo más pequeño donde:
    carga_ruta ≤ capacidad_vehículo × (1 + tolerancia)
  5. Si ningún vehículo cumple → la ruta queda sin vehículo.
